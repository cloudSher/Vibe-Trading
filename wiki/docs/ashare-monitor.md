# A 股观察台：资讯、统一计划与模拟轮换

这是公开资料驱动的观察与软件模拟功能，入口为 `/ashare`。它没有接入券商，不执行真实订单。研究分、新闻模型方向、回测和模拟结果均不是收益预测或保证。

## 数据和范围

- 龙虎榜池读取最近已披露的榜单日期，不能将历史上榜当作当日资金行为。
- 沪深主板扫描核对当日完整分页名录及代码唯一性，排除创业板、科创板、北交所、ST/退市以及N/C新股；量价初筛后保留有限候选持续取价。
- 主板资讯雷达使用有界公开快讯、公司名/明确证券代码匹配、个股相关搜索及公告索引。它不保证全市场全部利好无遗漏。行业关联不等于公司订单，摘要和标题检查不等于全文公告核验。
- 行情约30秒轮询，个股资讯、公告及模型整理受约5分钟批次、队列及公开来源延迟约束。页面约15秒同步。服务停止、电脑休眠、断网和来源故障会中断或延迟观察。
- 交易日必须由已支持年度的交易所日历核验。休市、未知日历以及持续资讯窗口外不自动采集；持续资讯默认窗口为北京时间交易日09:00—21:00，包含午间及盘后。盘前、午间、盘后只作准备或复盘。

每条资讯分别保存发布时间、抓取时间、来源、链接、直接/行业关联和匹配分析版本。新闻模型仅接收公开事件，不能读取账户或执行工具；逐条校验事件ID及原文连续摘录。没有匹配版本、直接负面/不确定或待整理消息时阻止联合观察确认。旧闻不作盘中新催化，模型整理不是事实核验。

## 统一观察计划和可复算排名

收盘后可生成下一已核验交易日的研究草案。研究记录固定资料截止时间、采集范围、候选排名、分项分数、原文依据及落选原因。名录、报价覆盖、分页或直接证据不足时停止生成，不补凑名单；板块映射缺失须明确缺口，不能虚构板块强度。

草案须由操作者核对后发布。发布计划具有 `plan_id`、连续 `version`、`content_hash`、目标日及逐股参考位。观察台、报告页与 Codex 中继读取同一身份，更新不会自动改真实账户、净值账本或公告限制。新雷达候选另列，不能覆盖原预测及其复盘。旧计划与风险背景归档保留，归档不等于风险解除。

研究分是可复算规则，未校准为收益或涨停概率。独立结果评估使用目标日真实收盘报价，缺失保持未知；它与实际交易收益及模拟组合表现分开。

## 量价观察与失效

只有计划目标日9:45后连续竞价可产生盘中确认；报价须90秒内、昨收口径匹配，且有真实当日完整5分钟K线。高开达到3%、偏离当日VWAP超过2%、成交额不足、换手过高或其他量价限制均阻止确认。

突破K线收盘高于计划突破位，前一根未突破；其成交量至少是此前连续三根均量的1.5倍。下一根完整K线须回踩至突破位上方0.2%以内、不破承接位且收盘保持其上。午休、缺根和未完成K线不拼接确认；确认最多保留10分钟，随后失守承接位或VWAP即取消。5分钟源失败可使用备用公开源，但不补造单根成交额或VWAP。

价格、公告新闻和账户风控分别判断。价格通过不能解除未核验、新增或负面公告，不得把 `entry_ready=false` 描述为买入确认。除权除息、旧报价或缺失K线需要重新核对。计划只对指定目标日有效，不能把已失效事件当作新买点。

## 账户和回撤口径

真实现金、持仓、可卖数量与历史高点由操作者在本地页面录入。默认回撤分级为3%预警、4%暂停新增、5%最大提醒阈值；操作者可在设置中明确调整，修改记录持久保存。实际页面及中继以当前 `risk_policy` 为准，不能沿用旧百分比或自动放宽。

可按当日确认的完整估值建立独立监测阶段；后续回撤使用阶段高点，同时保留原历史高点、历史亏损及风险事件。保存账户、出入金或重启不会自动重建基准。历史触发记录须标识是否仍为当前阶段条件，不能声称更换口径收回了亏损。

这些阈值是观察和提醒规则，无法保证实际损失不越线。真实交易由使用者决定并手动完成，新买A股受T+1约束。

## 独立模拟组合

模拟从操作者选择的虚拟资金开始，保存在独立 `paper-portfolio.json`，没有券商接口，不写真实账户或净值账本。基础计划身份冻结，重复创建幂等，不覆盖既有试验和历史。

每股预算最多为原始虚拟资金的10%，至少保留50%原始资金现金，最多五只实际虚拟持仓。风控策略从创建时的配置独立冻结。模拟按有效报价加每边0.10%不利滑点、每边0.15%摩擦成本假设计算，整手向下取整；这些是假设，不是券商实际税费或真实可成交证明。

只记录创建后的有效触发，不回填停机、旧信号或收盘价成交。当天新增仓不能当天卖出；失效记录待退出，须等已核验的下一交易日、新有效报价及成交限制通过后才模拟退出。缺失估值保持未知，不补零。原计划到期停止新增，已有模拟仓继续估值及跟踪退出。现金分红、送转及除权后的股数成本调整尚需单独复核。

### 盘中候补和自动轮换

“盘中发现与模拟轮换”有只提醒、确认后轮换和满足条件自动轮换三种模式。它仅修改独立模拟观察位，不修改发布计划或原排名。

新增候补必须具备近30分钟、当前分析版本的直接正向资讯，来源和个股公告索引新鲜，且没有当前或归档公告限制。操作者在页面核对本次资讯及公告原文后保存核对记录；来源、内容、模型版本或公告变化会使该核对失效。自动模式不替使用者勾选已阅读原文，也不自动解除公告风险。

候补参考位根据发现时已经完成的真实当日5分钟K线冻结，明确属于盘中参考而非昨日均价。随后满足上述突破和回踩，检查报价/VWAP、涨跌停边界及独立模拟风控；至少两次不同源时间报价、持续30秒通过，研究分比被换对象高至少10分才允许轮换。优先比较未建仓观察位，冷却30分钟，每日最多两次。

观察位切换、旧模拟仓待退出、新股模拟成交分别留档。旧仓受T+1及价格限制约束，未卖出不能假设释放资金，也不能从损益中消失。轮换履历保留来源核对、量价证据、分差与时间；盘中排名变化写独立 `paper-rotation-journal`。原五股预测、盘中模拟策略及真实账户分别复盘。

暂停模拟会停止新轮换与模拟执行，保留已有记录。轮换仍限基础计划目标日，不自动顺延。任何自动模式均不能保证盈利或最大损失。

## 本地提醒和 Codex 中继

本地后台自行采集、判断和更新模拟，不要求持续打开 Codex 会话。页面打开时可显示站内提醒；操作系统通知需本人授权，权限或系统休眠会影响送达。不默认连接外部消息平台。

后台原子生成公开缩减快照 `relay.json`；中继仅读该快照及写独立去重游标，不联网、不读账户明细。可在使用者授权的调度中调用：

```bash
PYTHONPATH=agent .venv/bin/python -m src.ashare.relay \
  --root .runtime/ashare --recurring \
  --plan-id <published-plan-id> --plan-version <version> --plan-hash <content-hash>
```

不匹配的身份停止转发并去重报告故障。窗口外、休市及 `notify=false` 安静；只有新资讯、方向/条件变化、风险、失败及有状态证据的恢复提醒。相同事件不重复，旧来源、旧版本及失效条件不冒充当前机会。

模拟候补、切换和成交必须带 `simulation=true` 且匹配基础计划身份。提醒明确标注“模拟”，切换不等于已卖出或新股已成交。公开中继不包含真实或模拟资金及股数，详细流水留在本地模拟页。

## 主要接口与本地验证

所有写接口使用原有本地写权限与版本守卫，不增加券商或外部消息权限。

| 接口 | 用途 |
| --- | --- |
| `GET /api/ashare` | 当前公开行情与本地观察台视图 |
| `POST /api/ashare/plan/publish` | 发布核对后的日期/版本计划 |
| `GET /api/ashare/plan` | 计划、公开风险状态与发布审计 |
| `GET /api/ashare/screening` | 冻结排名、草案、落选原因与结果评估 |
| `POST /api/ashare/screening/run` | 收盘后生成下一交易日草案 |
| `POST /api/ashare/screening/publish` | 按预期校验值发布草案 |
| `GET/POST /api/ashare/paper` | 查看/创建独立模拟组合 |
| `PUT /api/ashare/paper/status` | 暂停/继续模拟 |
| `PUT /api/ashare/paper/rotation` | 选择模拟轮换模式 |
| `POST /api/ashare/paper/candidate` | 保存当前来源原文核对或确认 |
| `GET /api/ashare/relay` | 不含账户明细的提醒快照 |
